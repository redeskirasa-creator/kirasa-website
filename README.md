# KIRASA Constructores

Sitio web corporativo de KIRASA Constructores.

Este repositorio es la fuente principal del proyecto web KIRASA.

## Estado
En desarrollo.

## Principios del proyecto
- Identidad visual corporativa, sobria y enfocada en construcción e ingeniería.
- Paleta principal: carbón `#1A1A1A`, amarillo construcción `#F4B000` y gris `#6B6F76`.
- Cada imagen, logo e icono utilizado debe existir como archivo independiente.
- No utilizar recortes de mockups o collages como recursos del sitio.
- Las imágenes conceptuales generadas con IA no se presentarán como proyectos reales de KIRASA.

## Flujo de trabajo
Banco multimedia → validación de assets → implementación del sitio → QA responsive → publicación.
