# Assets

## Directory policy
- `branding/`: logos and identity assets.
- `icons/`: independent interface/section icons.
- `images/hero/`: hero photography.
- `images/about/`: company/about imagery.
- `images/sectors/`: residential, commercial and industrial imagery.
- `images/process/`: design, planning, execution, supervision and delivery imagery.
- `images/projects/`: only authorized KIRASA project photography.

Do not add contact sheets, collages, website mockups or screenshots as production assets.
